# CS426-Final-Project

## Siege Stats: A data-driven look at using machine learning techniques to predict Rainbow Six Siege esport player earnings.

### Project Description
This project explores the use of scalable, reproducible data‐analysis pipelines and machine learning models to predict professional Rainbow Six Siege esports players’ earnings based on different numerical features such as number of podium placements (top 3), number of championships, and average earnings per podium placement.

### Objectives:
1. Collect and understand a comprehensive dataset
2. Pre-process and preform Exploratory Data Analysis (EDA) on the cleanded dataset
3. Build and test different machine learning models
4. Evaluate and optimize these models
